# ロードマップ

## 実装済み

- Discord Activity(埋め込み)起動、Discordアカウントのみでのログイン
- Trello風カンバンボード（ドラッグ&ドロップでステータス変更、インライン追加、優先度・期限・担当者）
- タスク詳細（本文の共同編集、プレゼンス、自動保存、競合検知、リンク/添付ファイル、それぞれの削除、期限時刻、カレンダー連携）
- チーム（Discordサーバー相当）配下に複数プロジェクト（かんばんボード）を持つ階層構造。チーム参加で全プロジェクトへ自動アクセス
- チームに1つの共通カレンダーで、全プロジェクトのタスク期限とチームの予定を横断表示（月間カレンダーでの予定作成/編集/削除を含む）
- チーム作成、メンバー招待/ロール変更/削除、招待取消、チーム脱退
- チーム設定（名前変更、Discord Webhook URL、連携サーバーID、リマインドタイミング）、プロジェクトの作成/名前変更/削除
- 設定したタイミングでタスクの期限・予定の開始をDiscord Webhookへ自動通知（チーム単位で1チャンネルに集約、pg_cron + pg_net、Botプロセス不要）
- `/task add` スラッシュコマンドからのタスク作成（Discord HTTP Interactions Endpoint、プロジェクト指定オプション対応）
- viewerロールの読み取り専用化、`profiles`の閲覧範囲を同一チーム内に限定

## 未実装（今後の候補）

- Discordメッセージからのタスク化、タスクごとのDiscordスレッド自動作成
- 全文検索、活動ログ（誰が何をいつ変更したか）
- カンバン列内でのカード並び替え（現状は列間のステータス変更のみ永続化）
- Google Calendar / Tasks / Docs連携（ログインとは別の外部サービス連携として、必要になったタイミングで追加）
