# 使用方法

Discord Task Activity（このアプリ）を実際に使うための手順書です。デプロイ自体の手順は `docs/DEPLOY.md` を参照してください。ここでは、デプロイ済みのアプリをDiscordユーザーとしてどう使うかをまとめます。

## 1. 起動方法

このアプリには2つの起動経路があります。

### 1-1. Discord Activityとして起動（本来の使い方）

1. Discordデスクトップアプリ（またはブラウザ版Discord）で、ボイスチャンネルに参加する。
2. ボイスチャンネル下部のロケットアイコン（アクティビティ起動）または「アプリを起動」から、このアプリ（Discord Developer Portalで設定した名前）を選択する。
3. 自動的にDiscordアカウントで認証され（許可ダイアログが出た場合は「承認」）、ボードが表示される。
4. 同じボイスチャンネルにいる他のメンバーも同じアクティビティに参加でき、リアルタイムに変更が同期される。

### 1-2. ブラウザから直接開く（フォールバック、開発・確認用）

VercelのURLを直接ブラウザで開いた場合、通常のDiscord OAuthログイン画面が表示されます。「Discordでログイン」ボタンを押すとDiscordの認可画面に遷移し、許可すると通常のWebアプリとして使えます（Activity外での動作確認用）。

## 2. 画面構成

左サイドバーに以下があります。

| 項目 | 内容 |
| --- | --- |
| チーム切替 | 所属している複数のチーム（後述）をプルダウンで切り替え。下の入力欄から新規チームも作成可能 |
| ボード | カンバン形式のタスク管理（メイン機能）。ボード内にさらにプロジェクト切替がある |
| カレンダー | チーム全体の予定・全プロジェクトのタスク期限をまとめて表示 |
| メンバー | チームメンバーの招待・権限管理 |
| 設定 | チーム名、Discord連携（Webhook・サーバーID）、プロジェクトの作成/名前変更/削除 |
| アカウント | 自分のDiscordアカウント情報（表示名・Discord User ID）の確認 |

右上のログアウトアイコンでログアウトできます。

## 3. チームとプロジェクト

このアプリは「チーム」と「プロジェクト」の2階層で構成されます。

- **チーム**: Discordサーバー1つに対応させることを想定した最上位の単位。Discordサーバー連携（Guild ID）、通知用Webhook、リマインド既定値、メンバーシップはすべてチーム側にひとつだけ存在します。
- **プロジェクト**: チームの中に複数作成できる、ボード（かんばん）単位。タスクはすべていずれかのプロジェクトに属します。チームに参加すると、そのチーム内の全プロジェクトに自動的にアクセスできるようになります（プロジェクトごとに個別の招待は不要です）。
- **カレンダー**はプロジェクト単位ではなくチームに1つだけあり、チーム内の全プロジェクトのタスク期限とチームの予定をまとめて表示します。

### チームの作成・切り替え・参加

- **作成**: サイドバーの「新しいチーム名」欄に入力して「作成」。作成した人が自動的に`owner`ロールになります。
- **切り替え**: サイドバー上部のプルダウンから選択。
- **参加**: 他人のチームには、そのチームの管理者から招待されることで参加します（後述の「メンバー」参照）。参加すると同時にそのチームの全プロジェクトへアクセス可能になります。
- チームが1つも無い状態では「チームがありません」という空表示になるので、まず自分でチームを作成するか、招待を待ってください。

### プロジェクトの作成・切り替え

- 「ボード」タブの上部にプロジェクト切替が表示されます。プルダウンで選択、隣の入力欄と「作成」ボタンから新規プロジェクトを作成できます。
- プロジェクトの名前変更・削除は「設定」タブの「プロジェクト」セクションから行います（admin以上）。プロジェクトを削除すると、そのタスクもすべて削除されます。
- プロジェクトが1つも無いチームでは「プロジェクトがありません」という空表示になります。

## 4. ボード（タスク管理）

Trello風のカンバンボードです。列は固定4つ: **未着手 → 進行中 → 確認待ち → 完了**。

### 4-1. タスクの作成

「未着手」列の下部にある入力欄にタイトルを入力してタスクを作成します（クイック追加）。

### 4-2. ステータス変更

タスクカードをドラッグ&ドロップして別の列に移動すると、ステータスが更新されます。

### 4-3. タスク詳細（カードをクリックして開くモーダル）

左側が本文（詳細・メモ・仕様）、右側にステータスなどの設定項目という2カラム構成です。

- **タイトル**: 上部の入力欄で編集可能（フォーカスを外すと自動保存）。
- **本文（左側、大きなテキストエリア）**: 自由記述のメモ欄。
  - 入力を止めてから**3秒後に自動保存**されます。
  - 直近の更新者のアイコン・名前・更新時刻が本文の上に表示されます。
  - 同じタスクを複数人が同時に開いていると、その人のアイコン付きで「〇〇が入力中/閲覧中」とプレゼンス表示されます。
  - 他のメンバーが先に保存していた場合は「他のメンバーが先に更新しました」という**競合検知**が表示され、「最新版を見る」（相手の内容に合わせる）か「自分の内容で上書き」かを選べます。
  - 保存状態は右上に「保存済み / 編集中 / 保存中 / 競合あり」で表示されます。
- **ステータス / 優先度（低・中・高・緊急） / 担当者**（右側）: プルダウンで変更すると即座に保存されます。
- **期限**（右側）: 日付に加えて時刻も任意で設定できます。時刻を空欄にすると終日扱いになります。期限を変更するとリマインド通知が再度そのタイミングで飛ぶようになります。通知タイミングはこのタスクだけ個別に上書きすることもできます（未指定ならチームの既定値を使用）。
- **概要**（右側）: 短い概要メモ。ここに書いた内容は「カレンダー」タブにも表示されます。
- **関連リンク**: `https://`で始まるURLのみ登録可能。表示名（任意）とURLを入力して「追加」。自分が追加したリンクのみ削除できます。
- **添付ファイル**: ファイル選択で即アップロード（Supabase Storage）。上限10MB、`.exe` `.bat` `.cmd` `.msi` `.apk` `.ipa`は拒否されます。画像はサムネイル表示され、クリックで拡大プレビューできます。ダウンロードは別ボタンから（元のファイル名のまま保存されます）。自分がアップロードしたファイルのみ削除できます。
- 右上のゴミ箱アイコンでタスク自体を削除できます（確認ダイアログあり）。

## 5. カレンダー

月間カレンダーが画面いっぱいに表示されます。日曜は赤、土曜は青、今日はアクセント色でハイライトされます。このカレンダーはチームに1つだけで、チーム内の**全プロジェクト**のタスク期限とチームの予定をまとめて表示します（プロジェクトごとのカレンダーはありません）。

- 期限が設定されているタスクは、カレンダー上に別の色のチップとして自動的に表示されます（どのプロジェクトのタスクかを示すプロジェクト名、タスク名、タスク詳細で入力した「概要」）。優先度に応じて左端の色が変わり、完了済みタスクは打ち消し線で表示されます。
- 日付をクリックすると、その場所の近くにポップアップが開き、その日の予定一覧・期限タスク一覧（タスクは参照のみ、編集は各プロジェクトのボードから）が表示されます。ポップアップの「追加」から予定を新規作成できます。
- 予定には開始時刻・終了時刻・詳細メモを設定できます。時刻はどちらも空欄にでき、空欄の場合は「終日」として扱われます。予定はプロジェクトに紐付かず、チーム直下のものとして作成されます。
- 一覧の鉛筆アイコンで編集、ゴミ箱アイコンで削除できます。
- 前月/翌月への移動、「今日」ボタンでの即時ジャンプができます。
- 予定開始が近づくと、後述のDiscord Webhook通知の対象になります。

## 6. メンバーと権限

### 6-1. ロールの種類

| ロール | 権限の目安 |
| --- | --- |
| `owner` | チーム作成者。全操作可能 |
| `admin` | メンバー招待・削除、ロール変更、チーム設定・プロジェクト管理の変更が可能 |
| `member` | タスク・予定の作成/編集など通常利用が可能（招待や設定変更は不可） |
| `viewer` | 閲覧のみを想定したロール |

設定画面（チーム設定）とメンバー管理画面の操作は`owner`/`admin`のみ表示されます。ロール・メンバーシップはすべてチーム単位で、チームに参加すると自動的にそのチーム内の全プロジェクトへアクセスできます（プロジェクトごとの個別権限はありません）。

### 6-2. メンバーを招待する（admin以上）

1. 招待したい相手のDiscordユーザーネームを確認してもらう。
2. 「メンバー」タブの入力欄にそのユーザーネームを入力すると候補がプレビュー表示されるので、付与するロール（admin/member/viewer）を選んで「招待」。
3. 招待は7日間有効です。
4. 招待された本人がこのアプリにDiscordアカウントでログインすると、招待が自動的に反映されチームに参加します（現状、招待を承諾する追加操作は不要で、ログイン時、またはアプリを開いたままの場合はリアルタイムに自動的にマッチングされる仕組みです）。参加すると同時にそのチームの全プロジェクトへアクセスできるようになります。

### 6-3. ロール変更・削除・脱退

- メンバー一覧でロールのプルダウンから変更可能（admin以上、自分自身は変更不可）。
- ゴミ箱アイコンでメンバーを削除可能（admin以上、自分自身は削除不可）。
- 自分がチームから抜けたい場合は、下部の「チームから脱退」ボタンを使用。

## 7. チーム設定とプロジェクト管理（admin以上）

「設定」タブで以下を設定できます。

| 項目 | 内容 |
| --- | --- |
| チーム名 | 表示名の変更 |
| 通知用Webhook URL | Discordのチャンネル設定 → 連携サービス → ウェブフック → 新しいウェブフック、で発行したURLを貼り付け。チーム内の全プロジェクトのタスクの期限・チームの予定の開始が近づくと、このWebhook宛のチャンネルへまとめて自動通知します |
| 連携するサーバーID（Guild ID） | 対象DiscordサーバーのIDを設定すると、そのサーバー内で `/task add` スラッシュコマンドが使えるようになります |
| タスクの期限リマインド | 期限の何分/時間/日前に通知するかを選択（0分前〜3日前）（チームの既定値）。時刻未設定のタスクは0:00扱いで計算されます。タスク詳細画面で個別に上書き可能 |
| 予定の開始リマインド | 予定開始の何分/時間/日前に通知するかを選択（チームの既定値、デフォルト1時間前）。予定の編集フォームで個別に上書き可能 |

同じ「設定」タブの下部「プロジェクト」セクションから、プロジェクトの作成・名前変更・削除ができます。プロジェクトを削除すると、そのプロジェクト内のタスクもすべて削除されるため注意してください。

## 8. Discordからの操作（スラッシュコマンド）

チームに「連携するサーバーID」を設定していると、そのDiscordサーバーの任意のテキストチャンネルから以下が使えます。

```
/task add title:<タスク名> due:<期限（省略可、YYYY-MM-DD）> project:<プロジェクト名（省略可）>
```

- 実行者がこのアプリに一度もログインしたことがない場合、または対象チームのメンバーでない場合は失敗します（先にアプリへログイン＆チーム参加が必要）。
- `viewer`ロールのメンバーはこのコマンドでタスクを作成できません（`owner`/`admin`/`member`のみ）。
- チームにプロジェクトが1つしかない場合は`project`を省略するとそのプロジェクトに追加されます。複数ある場合は`project`で名前を指定する必要があり、省略したり名前が一致しないと候補一覧が返信されます。
- 成功すると「✅「<プロジェクト名>」に「<タスク名>」を追加しました。」とそのチャンネルに（自分だけに見える形で）返信されます。

## 9. Discord通知（自動リマインド）

- チーム設定でWebhook URLを登録していると、チーム設定で決めたタイミング（期限/開始の何分〜何日前）になったタスク・予定について、Supabase側のpg_cronジョブが最大30分おきにチェックします。対象はそのチーム内の全プロジェクトのタスクとチームの予定で、いずれもチームに設定した1つのDiscordチャンネルへそれぞれ一度だけ通知を送ります。
- 期限やリマインド設定を変更すると、そのタスク/予定は再度通知の対象になります。
- 動作確認したい場合は、Supabase Dashboardの「SQL Editor」で以下を手動実行すると即座にトリガーできます。

```sql
select public.notify_due_tasks();
```

## 10. 困ったときは

- ログインできない/認証後に画面へ入れない、URLマッピングのエラーなど、デプロイ・設定に関する問題は `docs/DEPLOY.md` を参照してください。
- 想定外のエラーメッセージが表示された場合は、画面のスクリーンショットとエラー内容を添えて相談してください。
